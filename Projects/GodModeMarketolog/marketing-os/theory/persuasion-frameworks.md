# Theory: Persuasion Frameworks (Tony Robbins + Jane Street)

> **Источник:** Tony Robbins 1992 Persuasion Masterclass (Jane Street $600K framework).
> **Применение:** Копирайт, продажи, фандрайзинг, аутрич. Уровень Human-Led (L1).

## 1. The 6 Human Needs (Robbins)
Все люди имеют ВСЕ 6, но **top-2 driving 80% решений**.

| Need | Боль если нет | Persuasion lever | Язык маркетинга |
|------|---------------|------------------|-----------------|
| **certainty** | Тревога, страх | Гарантии, proof, трек-рекорд | "Proven", "Secure", "Reliable" |
| **variety** | Скука, застой | Новизна, "никогда не видели" | "Revolutionary", "First", "New" |
| **significance** | Незаметность | Статус, эксклюзивность | "Elite", "Top 1%", "Exclusive" |
| **connection** | Одиночество | Комьюнити, миссия | "Join", "Together", "Your tribe" |
| **growth** | Стагнация | Трансформация, мастерство | "Master", "Evolve", "Next level" |
| **contribution** | Пустота | Влияние, легаси | "Impact", "Change the world" |

**ID техники:** «Что для тебя самое важное в [нише]?» → слушай, что повторяется.
**Примеры аудиторий:**
- CTO → certainty + growth
- Founder → significance + contribution
- Privacy-audience → certainty (security) + connection (tribe)

## 2. The Dickens Pattern (Pain × Pleasure Leverage)
```
1. Current Reality   — признай где они сейчас
2. Future Pain       — Рождество будущего: НЕТ перемен (боль)
3. Future Pleasure   — Рождество будущего: ЕСТЬ решение (удовольствие)
4. Present Choice    — пивот: одно решение. Сейчас.
5. Call to Action    — конкретный шаг
```
Пример (GlobeVis → GIS Manager):
```
CURRENT: управляешь 50+ GIS-лицензиями, команда на десктопе
PAIN: 12 мес спустя — лицензии дорожают, $500K упущено, CTO спрашивает почему
PLEASURE: 12 мес спустя — мигрировали, режем cost 80%, 3 веб-контракта выиграны
PIVOT: разница между двумя будущими = одно решение. Сейчас.
CTA: 30-мин deep-dive в четверг
```

## 3. The Agreement Frame (никогда «нет»)
Вместо «Но...» / «Нет...» → «Я согласен И...» / «Понимаю И...»
| Возражение | Плохо | Agreement Frame |
|-----------|-------|-----------------|
| «Дорого» | «Но это окупается» | «Понимаю, бюджет важен. И поэтому — платишь только за use, $X/мес, не $200K как ESRI» |
| «Не сейчас» | «Но потом хуже» | «Понимаю, завален. И поэтому мы делаем 90% миграции сами. Окно в 30 мин на неделе?» |
| «Смотрим конкурента» | «Но мы лучше» | «Умно сравнить. И где мы отличаемся — [value]. Прислать сравнение side-by-side?» |
| «Надо спросить босса» | «Но ты решаешь» | «Конечно, пусть тоже. И я пришлю one-pager на 2 мин. Его email?» |

## 4. State Management (Физиология → Фокус → Язык)
Robbins: Emotion = Physiology + Focus + Language. Контроль состояния = контроль исхода.
```
Pre-call ritual:
  Physiology: stand tall, deep breaths (4-7-8), power pose 2 min
  Focus: визуализируй звонок идеально — они говорят yes
  Language: "I am prepared. I add value. This is conversation, not pitch."
During call:
  objection → pause, breath, "Great question." (objection = engagement)
  stuck → stand up, move (физиология меняет состояние)
```

## 5. Jane Street Persuasion Stack ($600K)
```
level_1: active_listening (mirror, label, validate)
         calibrated_questions ("How would you...?", "What would need to be true?")
         tactical_empathy
level_2: problem_agitation_solution
         social_proof_stack (peers → experts → data)
         risk_reversal (guarantee, pilot, opt-out)
level_3: identity_shift (помоги им увидеть себя тем, кто решает)
         values_alignment (top-2 needs)
         future_pacing (проживи успех так ярко, что реален)
```

## 6. Persuasion-Enhanced Sequence (на примере Explee/AGENT-3)
| Touch | Framework | Hook |
|-------|-----------|------|
| 1 | Problem-Agitation-Solution + Certainty | Боль → агитация → решение как логичный путь |
| 2 | Identity + Growth | «Ты тот, кто модернизировал стек» |
| 3 | Dickens Pattern | Будущее без перемен vs с переменой |
| 4 | Risk Reversal + Agreement Frame | «Понимаю, риск → 30-дней пилот бесплатно» |

## Hard Rules
- Персуазия = понимание + влияние на человеческие нужды. Не манипуляция ради вреда.
- Ответственность за этику и финал — у человека (L1).
- Top-2 needs аудитории определяются ДО копирайта, не угадываются.
