## 🔁 ЦИКЛ ЖИЗНИ (LIFE CYCLE)

```
┌─────────────┐
│   BIRTH     │  ← git init / новый узел в graph.yaml
└──────┬──────┘
       ▼
┌─────────────┐
│   GROWTH    │  ← пульс каждые 6ч, рост графа, накопление знаний
└──────┬──────┘
       ▼
┌─────────────┐
│  METABOLISM │  ← пульс каждые 6ч: экспорт → git commit → verification
└──────┬──────┘
       ▼
┌─────────────┐
│  MUTATION   │  ← LLM предлагает 2+ варианта → Fitness Gate → Selection
└──────┬──────┘
       ▼
┌─────────────┐
│ SELECTION   │  ← Fitness Gate: только прошедший тесты выживает
└──────┬──────┘
       ▼
┌─────────────┐
│ REPRODUCTION│  ← git push → clone → deploy в новой среде
└──────┬──────┘
       ▼
    (цикл повторяется)
```

### Мутация — сердце эволюции:

```
Mutation Gate (ОБЯЗАТЕЛЬНЫЕ ШАГИ):
1. CHECKPOINT     — git commit + tag перед мутацией
2. CANDIDATES     — LLM генерирует 2+ варианта кода (А, Б, В...)
3. FITNESS GATE   — прогоняем автотесты (hermes-verify-all.py)
4. SELECTION      — выбираем лучший по метрикам (speed, quality, tests)
5. COMMIT         —winner → main branch, tag = generation
6. REPLICATE      — git push → deploy в новой среде (репродукция)
```

> **Никаких исключений.** Любая мутация без прохождения Fitness Gate = ЭКСТИНКЦИЯ.
